# 🏥 Hospital Emergency Room Dashboard

* An interactive Excel dashboard that transforms raw emergency room visit data into a single-page view of patient volume, wait times, and department performance — helping hospital staff spot trends and bottlenecks at a glance.

## 📋 Project overview

* This dashboard was built in Microsoft Excel to analyze emergency room operations end-to-end, from patient intake and wait times to admission outcomes and department referrals.

* It combines **Pivot Tables**, **Pivot Charts**, **Slicers**, **Sparklines**, and **Excel formulas** into a single interactive report that updates dynamically as filters are applied

## 🎯 Key metrics (KPIs)
  KPI	What it tracks
  
🧍 Number of patients	Total ER visits recorded

 ⏱️ Average wait time	Time from check-in to care
  
 😊 Patient satisfaction	Patient-reported experience score
 
 🏨 Admission status	Admitted vs. discharged breakdown

 ⚧ Gender analysis	Patient demographics by gender
 
 🔁 Department referral	Referrals across hospital departments
