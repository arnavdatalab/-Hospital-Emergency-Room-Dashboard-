# -Hospital-Emergency-Room-Dashboard.

## Project Overview
Interactive Hospital Emergency Room Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, Sparklines, and Excel formulas.

## Tools Used
•	Microsoft Excel
•	Pivot Tables
•	Pivot Charts
•	Sparklines
•	Slicers
